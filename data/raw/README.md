# Raw data

**This folder is intentionally empty in the repository.**

The raw Transfermarkt CSVs are public Kaggle data and are not redistributed
here. See [`docs/DATA_SOURCES.md`](../../docs/DATA_SOURCES.md) for the source
links, the exact files used, row counts, the frozen archive's SHA-256, and
instructions for the three pipeline stages that need them.

Unpack the CSVs into this folder if you want to re-run those stages. They are
excluded by `.gitignore` and will not be committed.
